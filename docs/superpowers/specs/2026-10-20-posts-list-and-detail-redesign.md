# /posts 목록·글 상세·홈 카드 정리

## 배경

/posts 검토(2026-10-20)에서 찾은 문제:

- 모바일 검색창 높이가 18px로 찌그러짐 (세로 flex에서 `flex-1`이 높이를 0 기준으로 만듦)
- 데스크톱 날짜 칸이 60px로 눌려 세 줄로 깨짐
- 모바일 첫 글이 745px에서 시작 (상단 카테고리 패널 + 검색 패널 + 탭이 겹침), 카드 1개 308px
- 카테고리가 상단 패널과 탭에 두 번 나옴
- 검색하지 않아도 "검색되었습니다" 문구
- 카드·그림자·큰 버튼 스타일이 홈과 다르고, 모노 글꼴·대문자 라벨이 AI가 만든 화면처럼 보임

## 결정

시안 v2(scratchpad 목업)를 기준으로 한다. 사용자 승인 2026-10-20.

### /posts 목록

- 제목 "글 {전체 개수}" 한 줄. 데스크톱은 제목 오른쪽에 검색창, 모바일은 아래.
- 검색창: 테두리 38px, 모서리 8px, 돋보기 아이콘, Enter로 제출. 버튼 없음.
- 카테고리: 텍스트 버튼, 선택만 진하게 채움. 모바일은 가로 스크롤 한 줄.
- 검색·필터 중일 때만 결과 문구와 "지우기".
- 목록: 카드 대신 가는 줄. `<article>` 안에 `<h2>` 제목 링크와 `<time datetime>` 날짜(데스크톱 같은 줄 오른쪽), 설명 1줄(모바일 2줄), `카테고리 · N분`. 태그는 목록에서 뺀다.
- 페이지네이션: "이전 1 2 3 다음".
- /posts에서는 모바일 상단 카테고리 패널을 숨긴다.
- 글꼴은 Pretendard만. 숫자는 `tabular-nums`.

### SEO

- `?page=N`(필터 없음)은 색인 허용, canonical은 자기 자신, 제목에 페이지 번호.
- 검색어·카테고리·태그 필터는 지금처럼 noindex, follow.
- 목록 페이지에 `CollectionPage` + `ItemList` JSON-LD.

### 글 상세

- 머리: 카드를 걷어내고 breadcrumb, h1, 설명, `날짜 · N분 · 수정일` 한 줄, 태그는 `#태그` 텍스트 링크.
- 작성자 박스: 카드·대문자 라벨 제거, 위 줄로 구분한 짧은 블록.
- 관련 글: 계산만 하고 쓰지 않던 `relatedLinks`를 본문 뒤 목록으로 표시(내부 링크).
- 이전/다음 글: 카드 대신 위아래 줄로 구분한 두 칸.
- 목차: "목차" 제목을 작은 라벨로, `<nav aria-label="목차">`.

### 홈

- 프로젝트 카드의 SVG 썸네일(`ProjectGlyph`, `.project-glyph-*`)을 지운다.
- 홈 히어로 최근 글 날짜, 프로젝트 카드 기간·태그의 `font-mono`를 Pretendard + `tabular-nums`로 바꾼다.
- About·Projects의 모노 글꼴은 이번 범위에서 제외.
